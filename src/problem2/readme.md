# Swap Currency App

A responsive currency swap application built with JavaScript, Bootstrap, and Vite.

## Features

- **Responsive Design:**  
  Uses Bootstrap’s grid and utilities for seamless experience across desktops, tablets, and mobile devices.

- **Bootstrap Theming:**  
  Follows Bootstrap’s theme guidelines for easy future adaptation (e.g., dark mode).  
  To switch themes, update Bootstrap’s SCSS variables or import a different Bootstrap theme.

- **Currency Swap:**  
  Swap between tokens with real-time feedback and validation.

- **Bootstrap Icons:**  
  Integrated for a modern and intuitive UI.

## Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- npm

### Install Dependencies

```bash
npm install
```

### Run in Development Mode
```bash
npm run dev
```
Open your browser at the URL shown in the terminal (http://localhost:3000).

### Build for Production

```bash
npm run build
```
The output will be in the `src/dist` folder.

### Customization
Theming: To adapt to dark mode or other Bootstrap themes, modify SCSS variables in `src/global_style.scss` or import a different Bootstrap theme.
